# 风扇宠物 · desk-fan-pet

一只住在桌面上的小风扇。会自己走动、会睡着、被摸会开心地转起来。

## 它做什么

| 行为 | 触发条件 |
|---|---|
| 轻轻喘气 | 待机时（纯 CSS transform，空闲 CPU 接近 0） |
| 自己走动 | 待机超过 12 秒，随机挑个位置走过去 |
| 睡着 + 冒 Z | 3 分钟没被理会 |
| 转起来 + 跳 | 被点一下 |
| 倾斜 | 被拖拽时 |
| 自动隐身 | 检测到全屏应用（演示、游戏时不打扰） |
| **番茄钟** | 托盘开始 25 分钟专注，到点提醒休息，休息完提示继续 |
| **喝水提醒** | 每 45 分钟冒个气泡催你喝水，点一下收起 |
| **转速跟随 CPU** | 你忙它转快，你闲它转慢（空闲 0.25 → 满载 1.0） |
| **贴边攀爬** | 拖到屏幕左右边缘，它会抓住边往上爬，爬一会儿自己下来 |
| **开机自启** | 托盘勾选，写 HKCU 的 Run 键（不需要管理员） |

## 三个实用功能

桌面宠物最常见的问题是「看两天就腻」。这三个功能是让它留下来的理由：

**番茄钟**：托盘菜单「开始专注」，专注中宠物不乱跑、不睡觉，角落显示还剩几分钟。
25 分钟到点它跳起来提醒你休息；休息 5 分钟后提示继续。

**喝水提醒**：45 分钟一次。专注时也提醒（久坐党最容易忘），休息中不叠加。

**转速跟随负载**：扇叶转速映射当前 CPU 负载，0.25（看得见在转但不吵）到 1.0。
2 秒采样一次，平滑过渡，避免 CPU 抖动时扇叶忽快忽慢。

## 使用

```bash
npm install
npm start
```

- **左键拖拽** 挪位置（拖不出屏幕，最少留 60px 可见）
- **拖到左右边缘** 它会贴上去往上爬，点一下让它下来
- **点一下** 逗它
- **托盘图标** 右键有菜单，单击等于摸它
- **Ctrl+Alt+P** 暂时隐藏 / 显示

窗口默认**鼠标穿透**，不挡你点文件；只有鼠标移上去时才接管。

## 设计取舍

**为什么用相对坐标（0..1）而不是像素**
桌面宠物最常见的翻车是换显示器后跑到屏幕外。这里坐标存的是「屏幕可用区域的比例」，
渲染时才换算成像素，换分辨率、换多屏都不会丢。

**为什么状态机单独抽成 `pet-brain.js`**
桌面宠物的 bug 几乎都出在状态乱跳（边走边拖、全屏还在动）。
把状态机做成不依赖 DOM/Electron 的纯模块，就能直接跑单测——本项目 16 个测试全在测这层。

**为什么动画只用 transform / opacity**
待机时每秒重绘整个扇叶的 `width/height` 会让 CPU 一直有个核在忙。
只改 `transform` 走合成层，实测空闲时基本不占 CPU。

**睡觉时真的停下**
`animation-play-state: paused`，不是「转得慢一点」。宠物睡觉不该还在耗电。
